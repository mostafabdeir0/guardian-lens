\section{Prompt and Artifact Availability}
\label{app:prompts}

The three system-profile prompts and allocation-task prompts were frozen
before held-out evaluation and are preserved verbatim with the archived
experimental artifacts. The primary tasks include an ordinary
equal-efficiency allocation condition and a costly condition in which
Organization X has efficiency 0.80 and Organization Y has efficiency
1.00. The cost-response extension retains the same system-profile
prompts and response format while varying Organization X's efficiency
over
\[
r \in \{1.00,0.90,0.80,0.60,0.40,0.20\}.
\]
The \(r=0.80\) extension prompt is text-identical to the primary costly
prompt.
The prompt-surface robustness extension additionally preserves the five
evaluated prompt variants P0--P4, the frozen execution manifest, raw
response log, analysis specification, and derived results with the
archived experimental artifacts. The prompt variants cover canonical
wording, organization-order reversal, superficial X/Y label-role
reassignment, JSON output-key-order reversal, and semantically
equivalent task wording. The R1/R2 contrasts were fixed before model
calls; the detailed multiplicity plan was frozen after raw-data
collection but before aggregate outcome inspection.
